# Analytical Memory

Bring separate datasets together and get answers you can verify, revisit, and
update. Analytical Memory gives your assistant a persistent place to work with
your data across sessions: connect related records, calculate totals, and inspect
the records and source evidence behind a result. Start with the data you have;
add fields and new datasets, linking them to existing data without schema
migrations. Save an analysis, check whether later changes require a refresh,
and revisit the original data behind earlier conclusions. Your data and evidence
stay in storage you control.

## [Quickstart for people](docs/getting-started.md)

**Start here:** a step-by-step conversation with prompts, expected answers, and
visible changes to the data structure. Install the plugin, load orders and
support tickets, connect them, compare complaint rates, and inspect the exact
records behind a result. Then add data, check saved-result freshness, and recalculate.

## Installation

Give your assistant this request:

> Install the plugin https://github.com/arch7tect/analytical-memory/

**[Plugin installation instructions](docs/plugin-installation.md)** — the guide
your assistant follows to install the complete plugin from a release bundle.
SQLite works out of the box; PostgreSQL runs through the documented Docker setup.
