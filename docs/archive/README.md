# Design history

These records explain past requirements, decisions, and delivery checks. They
are not installation instructions or current operation specifications. Use the
[current documentation](../README.md) for supported behavior and the
[backlog](../backlog.md) for deferred ideas.

- [ADR 0001](../decisions/0001-dynamic-ontology-query-ir.md): accepted dynamic
  ontology and Query IR contracts, with subsequent clarifications.
- [ADR 0002](../decisions/0002-native-analytics-observations.md): native analytics
  and immutable observations, implemented in 0.7.0.
- [Implementation history](../implementation-plan.md): completed milestone
  acceptance criteria; milestones 0–4 describe a superseded ingestion model.
- [Native analytics delivery](../native-analytics-delivery.md): implementation
  choices, verification and initial limits for 0.7.0.
- [Archived native analytics proposal](native-analytics-and-quickstart.md):
  original requirements and expected fixture results, accepted and implemented
  in 0.7.0. Later quickstart changes supersede its runner-based presentation.

History is retained in the repository and excluded from installed plugin bundles.
