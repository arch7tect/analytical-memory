# Installation entry point

Install the complete [Analytical Memory plugin](plugin-installation.md).
The plugin includes its MCP server and shared skills; MCP is not a separate
installation route.

For OpenCode or another generic host, follow
[generic environments: OpenCode](plugin-installation.md#generic-environments-opencode).
That section connects both parts of the same plugin and includes verification.

For protocol and configuration details after installation, see the
[MCP reference](reference/mcp.md). This page preserves the previous documentation
address so existing links still reach the current installation guide.
